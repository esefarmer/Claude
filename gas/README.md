# 単位認定会議資料（KS_成績確認システム 連携版）

「KS_成績確認システム」の Apps Script に追加して使うスクリプトです。
成績確認システムの判定結果（履修不認定・単位不認定）と、取込フォルダのクラス評定一覧を合わせて、
単位認定会議資料のスプレッドシートを結果フォルダに作ります。

## 導入（1回だけ）
1. KS_成績確認システムを開き、［拡張機能］→［Apps Script］
2. ファイルの「＋」→［スクリプト］で `会議資料` を作り、`会議資料.gs` の中身を貼り付けて保存
3. 既存の `onOpen()` の中に次の1行を追加して保存
   ```js
   KG_addMenu();
   ```
4. スプレッドシートを開き直すと、メニューに「単位認定会議資料」が出ます

関数名はすべて `KG_` で始まるので、既存のコードとは重なりません。Drive の変換（Advanced Drive API）は使わず、
xlsx を直接読みます（取込時の「User rate limit exceeded」の影響を受けません）。

## 設定シートに追加される項目
初回実行時、設定シートの末尾に次の行が既定値で追加されます。

| 項目 | 既定値 | 内容 |
|---|---|---|
| 推薦生徒一覧URL | （空欄） | クラブ推薦生徒一覧（見出し: 年・組・番・所属）のスプレッドシートのURL |
| 登校不調_欠席日数 | 10 | 欠席がこの日数以上で登校不調 |
| 登校不調_遅刻回数 | 10 | 遅刻がこの回数以上で登校不調 |
| 評定平均上位の人数 | 30 | 学年ごとの上位者一覧の人数（同順位は全員） |
| 推薦生徒_要確認の評定平均 | 3.0 | 推薦生徒の評定平均値がこれ未満なら「要確認」 |

## 使い方
1. いつもどおり成績確認を実行する（最新の結果ブックが実行ログに記録される）
2. メニュー［単位認定会議資料］→［会議資料を作成］
3. 結果フォルダに `年度_判定時期_単位認定会議資料_日時` ができる

## 作られるシート
| シート | 内容 | 元データ |
|---|---|---|
| 概要 | 学年別の件数、判定基準、注意 | — |
| 不認定一覧 | 履修不認定・単位不認定（欠時数／上限、推薦の所属付き） | 成績確認結果「科目別 不認定者一覧」 |
| 評定平均上位 | 学年別 上位30名 | クラス評定一覧 |
| 皆勤者一覧 | 欠席・遅刻・早退0、評定平均値・学年内順位付き | クラス評定一覧 |
| 登校不調者一覧 | 欠席10日以上 または 遅刻10回以上 | クラス評定一覧 |
| 推薦生徒 成績確認 | 推薦生徒ごとの評定平均値・学年平均との差・順位・評定1/2・不認定・要確認の理由 | ＋推薦生徒一覧 |
| 所属別 評定平均 | クラブ・コース（FA/B・FA/E）ごとの平均・最高・最低・学年平均との差 | ＋推薦生徒一覧 |
| 科目別評定分布 | 学年別・科目別の評定5〜1の人数 | クラス評定一覧 |
| クラス別比較 | クラスごとの平均・不認定・皆勤・登校不調 | 両方 |
| 生徒一覧 | 基礎データ | 両方 |

## 判定の考え方
- 履修不認定・単位不認定は成績確認システムの判定をそのまま使う（欠時数が授業時数の1/3以上＝履修不認定）
- 評定平均値は評定のついた科目の単純平均。評定のない生徒・異動者シートの生徒は順位・平均から除く
- 推薦生徒一覧の「◎」は除き、「女子サッカー」→「女子サッカー部」のように既存の部名にそろえる
  （そろえた結果は「所属別 評定平均」シートの下に表示）
- 「ＦＡ/Ｂ」「ＦＡ/Ｅ」はコースとして、クラブと同じ方法で集計する
