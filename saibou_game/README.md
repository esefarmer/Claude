# セルクエスト（高校「生物」細胞の構造ゲーム）

細胞の構造・細胞骨格・細胞接着を、4つのゲームで学ぶ教材です。
本体は単一のHTML（`index.html`）なので、ネットにつながらなくても動きます。
GAS（`コード.gs`）を使えば、得点と誤答をスプレッドシートに記録できます。

## ゲームの内容

| ゲーム | 内容 | 授業モード | 自習モード |
|---|---|---|---|
| 🎯 細胞図クリック | 動物細胞・植物細胞・小腸上皮細胞の模式図で、指定された構造をクリック | 10問（細胞骨格2問・上皮4問を含む） | 全28問 |
| ⏱️ タイムアタック4択 | 制限時間内に4択を連続で解く。コンボボーナスあり、誤答は−3秒 | 60秒 | 150秒（全44問から出題） |
| 🧩 分類チャレンジ | カードをドラッグ（またはクリック→箱をクリック）で分類 | 細胞骨格・細胞接着 各9枚 | 4ラウンド（＋モータータンパク質・細胞の種類）全46枚 |
| 🚀 ミクロ探検隊 | 探査艇で上皮細胞に潜入するストーリー。誤答でエネルギーが減る | 8ステージ9問 | 11ステージ17問 |
| 📖 細胞図鑑 | 得点なしの観察モード。部分をクリックすると名前と働きが出る | — | — |

- 毎問、1〜2文の解説が出ます。結果画面では、まちがえた問題を解説つきでふり返れます。
- 出題順と選択肢は毎回シャッフルされます。
- 自己ベストは端末のブラウザに保存されます（モード別）。
- 用語は東京書籍「生物」に合わせるつもりで書いていますが、教科書の表記と照らし合わせて確認してください。
  問題文は `index.html` の `PARTS`・`QUIZ`・`SORT_ROUNDS`・`MISSION` にまとまっていて、直接書きかえられます。

## 配布方法（3通り）

### 方式A：GASで配信する（Chromebook ではこれがおすすめ）
生徒にはURLを1つ配るだけです。記録は組織内のアカウントに限定でき、Googleアカウントのメールアドレスも記録されます。

1. 記録用のスプレッドシートを新しく作り、［拡張機能］→［Apps Script］を開く
2. 最初からある `コード.gs` の中身を、このフォルダの `コード.gs` で置きかえて保存する
3. ファイルの「＋」→［HTML］で `index` という名前のファイルを作り、`index.html` の中身をすべて貼り付けて保存する
4. ［デプロイ］→［新しいデプロイ］→ 種類「ウェブアプリ」を選び、次のように設定してデプロイする
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**
5. 初回は権限の承認画面が出るので許可する
6. 表示された「ウェブアプリのURL（…/exec）」を Google Classroom などで生徒に配る

### 方式B：HTMLファイルを配り、記録はGASに送る
GASのURLを開けない環境や、ファイルで配りたい場合に使います。

1. 方式Aの 1〜2 を行う（`index` のHTMLファイルは無くてもかまいません）
2. デプロイ時の「アクセスできるユーザー」を **全員** にする
   （HTMLファイルからの送信は、Googleにログインしていない扱いで届くためです）
3. `index.html` の上の方にある `GAS_URL: ''` に、ウェブアプリのURLを書き込む
   ```js
   const CONFIG = {
     GAS_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
   };
   ```
4. この `index.html` を生徒に配る

> **Chromebook での注意**：ドライブや Classroom に置いたHTMLファイルは、プレビューで開くとゲームとして動きません。
> いったん「ダウンロード」してから、ファイルアプリでダブルクリックして Chrome で開く必要があります。
> この手間を省けるので、Chromebook では方式Aをおすすめします。

- 送信できなかった記録は端末に残り、次にゲームを終えたときに自動で再送されます。
- 方式Bの送信方法では、届いたかどうかをブラウザ側で確かめることができません。最初に1回試して、シートに行が増えることを確認してください。
- 「全員」に公開したURLは、ほかの人が知れば誰でも送信できます。URLは授業内だけで共有してください。

### 方式C：HTMLファイルのみ（記録なし）
`index.html` をそのまま配ります。`GAS_URL` が空欄なら、結果は画面に出るだけです。

## スプレッドシートに作られるシート

| シート | 内容 |
|---|---|
| 記録 | 1プレイ1行。受信日時・講座・番号・氏名・ゲーム・モード・得点・正答数・出題数・正答率・所要時間・誤答した問題・Googleアカウント（方式Aのみ） |
| 誤答ログ | 誤答1件1行。問題IDごとの集計やピボットテーブルに使えます |
| 誤答集計 | メニュー［セルクエスト］→［誤答集計を更新］で作り直します。誤答の多い問題順に、誤答した生徒数とよくある誤答を表示 |

問題IDのつけ方：`Q01`〜（4択）、`S01`/`J01`/`M01`/`O01`〜（分類）、`M01-1`〜（探検隊の問題）、`D-animal-mt` など（細胞図）

## コードを更新したとき（方式A）
`index.html` の中身を貼りかえたあと、［デプロイ］→［デプロイを管理］→ 鉛筆アイコン →
バージョン「新バージョン」→［デプロイ］を押します。こうすると、URLを変えずに中身だけ更新できます。
