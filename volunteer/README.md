# ボランティア受入規程・様式（京都翔英高等学校）

京都教育大学「学校ボランティアハンドブック」と同大学の各様式を参考に、高等学校側の受入規程と書類一式を作成したもの。

| ファイル | 内容 | 対象 |
|---|---|---|
| 01_京都翔英高等学校ボランティア受入規程.docx | 規程（全22条・附則） | 教職員 |
| 02_ボランティア活動の手引き.docx | 心得・遵守事項・来校から退校まで・緊急時・手続き | ボランティアに配布 |
| 03_ボランティア受入様式集.docx | 様式第１号～第７号 | — |

## 様式一覧

| 様式 | 名称 | 記入者 → 提出先 |
|---|---|---|
| 第１号 | ボランティア活動申込書 | 本人 → 担当教員 |
| 第２号 | 誓約書 | 本人 → 担当教員 |
| 第３号 | ボランティア受入伺 | 担当教員 → 教頭 → 校長 |
| 第４号 | ボランティア受入決定通知書 | 校長 → 本人（担当教員経由） |
| 第５号 | ボランティア活動記録票 | 本人記入・担当教員確認 |
| 第６号 | ボランティア活動証明書 | 校長（求めに応じ発行） |
| 第７号 | ボランティア受入台帳（横） | 教頭 |

## 作り直す場合

```bash
node build.js   # docx（npm）が必要
```

文言を変えるときは `build_kitei.js`（規程）、`build_tebiki.js`（手引き）、`build_yoshiki.js`（様式）を編集する。Word で直接修正してもよい。
