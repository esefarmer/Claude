# 校内ポータル（掲載台帳連動）

掲載台帳のスプレッドシートを読み、教職員用・生徒用のリンク集を表示する Google Apps Script のウェブアプリです。

- 台帳に行を足して「掲載状況」を「掲載中」にすると、カードが増えます。
- 閲覧者が教職員か生徒かをサーバー側で判定し、生徒には生徒向けの項目だけを送ります。
- 「校外秘」に印のある項目は、掲載先が「両方」「生徒用」になっていても生徒には出しません。

## ファイル

| ファイル | 内容 |
|---|---|
| `Code.gs` | 台帳の読み込み、教職員の判定、メニュー |
| `index.html` | 画面（カード型のリンク集） |

## 台帳に必要な列

「台帳」シートの 1 行目に次の見出しが必要です。列の順番は自由です。

| 見出し | 必須 | 使い方 |
|---|---|---|
| 名称 | ○ | カードの題名 |
| カテゴリ | ○ | 見出しと上部メニュー。台帳に最初に出てきた順に並ぶ |
| 掲載先 | ○ | `教職員用` / `生徒用` / `両方` |
| 掲載状況 | ○ | `掲載中` の行だけ表示 |
| URL | | `http://` か `https://` で始まるもの。空ならカードは押せない |
| 一言説明 | | カードの説明文（見出しが「一言説明」で始まっていればよい） |
| 校外秘 | | 何か入っていれば校外秘。教職員には印を表示し、生徒には出さない |
| 種別 | | カード下の小さなラベル |

## 設置手順

1. 掲載台帳のスプレッドシートを開き、「拡張機能」→「Apps Script」を選ぶ。
2. 最初からある `コード.gs` の中身を消し、`Code.gs` の内容を貼り付ける。
3. 「ファイル」の「＋」→「HTML」で `index` という名前のファイルを作り、`index.html` の内容を貼り付ける。
4. 教職員の判定方法を決める（下の「教職員の判定」）。
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選び、次のように設定する。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **（学校のドメイン）内の全員**
6. 表示された URL がポータルの入口になる。初回は権限の承認を求められる。

「自分として実行」にするため、閲覧者に台帳そのものを共有する必要はありません。台帳は編集する先生だけに共有してください。

コードを直したあとは、「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」で更新します。URL は変わりません。

## 教職員の判定

どちらか一方を使います。

- **「教職員」シートで判定（初期設定）**: スプレッドシートに「教職員」という名前のシートを作り、A1 に見出し、A2 以降に教職員のメールアドレスを 1 行ずつ入れる。
- **Google グループで判定**: 教職員のグループがある場合、`Code.gs` 冒頭の `STAFF_GROUP` にそのアドレスを入れる。デプロイした人がそのグループのメンバーを見られる必要がある。

どちらにも当てはまらない人は生徒として扱います。設定を誤っても、教職員用の項目が生徒に出る方向には倒れません。

## 日々の運用

- 台帳の変更は最長 5 分で反映されます（`CACHE_SECONDS`）。すぐ反映したいときは、スプレッドシートのメニュー「ポータル」→「台帳の変更を今すぐ反映」を使います。
- 「ポータル」→「掲載内容を確認」で、掲載中の件数と、校外秘のため生徒に出ない項目、URL が無効な項目を確認できます。
- 教職員には「教職員用／生徒用」の切り替えボタンが出ます。生徒用の見え方を確かめるためのものです。

## 注意

- ポータルが隠すのはリンクの一覧だけです。リンク先のファイルが「リンクを知っている全員」で共有されていれば、URL を知った人は開けます。校外秘の資料は、リンク先の共有設定も確認してください。
- 「自分として実行」では、全員のアクセスがデプロイした人の実行枠を使います。同時実行は 30 件までのため、全校生徒が同じ瞬間に開くと一部でエラーが出ることがあります。台帳をキャッシュして 1 回の処理を短くしていますが、朝の一斉アクセスで問題が出ないかは試験運用で確認してください。
- 生徒用 Chromebook の起動時ページやブックマークへの配信は、Google 管理コンソールで設定します。

## 確認済みの範囲

台帳を模したデータで、次の点を確認しています（Apps Script 上での実行は未確認）。

- 教職員には教職員用・両方の項目が、生徒には生徒用・両方の項目だけが渡る。
- 校外秘の項目は、掲載先が「両方」でも生徒に渡らない。
- 「準備中」の行、名称が空の行は表示されない。
- `http(s)` で始まらない URL はリンクにならない。
- 台帳に HTML の記号が入っていても、文字としてそのまま表示される。
