# こども性暴力防止法対応 文書一式（学校法人明珠学園・京都翔英高等学校）

こども性暴力防止法（令和6年法律第69号、令和8年12月25日施行）に対応するための、就業規則の改正案と運用文書一式（案）です。
最初に `00_整備概要・要確認事項.docx` を読んでください。施行までのスケジュール、学校で記入する【 】の一覧、専門家の確認が必要な点をまとめています。

| ファイル | 内容 |
|---|---|
| `00_整備概要・要確認事項.docx` | 全体像、法の要点、改正点、スケジュール、要確認事項、未改正の気づき |
| `01_就業規則（改正案）.docx` | 現行就業規則に改正を反映したもの（書式は現行どおり） |
| `01b_就業規則_新旧対照表.docx` | 改正箇所の現行・改正案・理由 |
| `02_児童対象性暴力等対処規程.docx` | 基本規程（体制、未然防止、防止措置、調査、保護・支援、再発防止） |
| `03_犯罪事実確認・情報管理規程.docx` | 犯罪事実確認の手続と情報管理（公式ひな型②ベース） |
| `04_相談窓口設置要領.docx` | 相談員・相談窓口・外部窓口 |
| `05_性暴力事案発生時の対応マニュアル.docx` | 報告ルール（全教職員）・対応ルール（対応チーム） |
| `06_教職員向け研修資料・誓約書.docx` | 法定8項目の研修資料、演習、確認テスト、誓約書 |
| `07_様式集（…）.docx` | 相談受付票、事実確認記録票、対応記録票ほか全8様式 |
| `08_採用時の確認・誓約に関する書式.docx` | 募集要項記載例、誓約書、内定通知書記載例、通知書、契約条項、参照条文 |
| `09_保護者・生徒への周知文書.docx` | 保護者宛、生徒向け、掲示用、ホームページ掲載文 |

## 注意

- 一式は「案」です。理事会の決定、過半数代表者の意見聴取、顧問弁護士・顧問社会保険労務士の確認を経て確定してください。
- こども家庭庁のガイドライン（令和8年9月2日改訂）と公式ひな型・参考例（令和8年11月11日時点）に基づいています。
- 文中の【 】は学校で記入する箇所です。

## 再生成の方法（`_src/`）

```bash
cd _src
bash build_all.sh
```

- `content/*.txt` … 各文書の原稿（簡易マークアップ。記法は `build.js` 冒頭参照）
- `build.js` … 原稿から Word 文書を生成（Node.js、`docx` パッケージ）
- `edit_shugyo.py` … `就業規則_現行.docx` を展開したフォルダに改正を反映し、`amend.json`（改正箇所）を出力
- `make_shinkyu.py` … `amend.json` から新旧対照表の原稿を生成
