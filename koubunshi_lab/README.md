# 高分子ラボ（生物の高分子を学ぶゲーム教材）

高校「生物」を学ぶ生徒向けの学習アプリです。化学を履修していない生徒も対象です。
糖類・タンパク質・脂質・核酸とATPを、ゲーム感覚で学べます。
ファイルは `index.html` の1つだけです。サーバーやログインは要りません。インターネットにつながっていなくても動きます。

## 内容

| 部屋 | 形式 | 内容 |
|---|---|---|
| 🧪 合成ルーム | 分子組み立てパズル（10ステージ） | マルトース・スクロース・ラクトース・デンプン・ペプチド・脂肪・ヌクレオチド・DNAの相補鎖・RNAへの転写・ATP。つなぐと「H₂O」が抜けるアニメーションが出ます。構造式モードでは –OH や –COOH などの変化が見えます |
| 🗂️ 分類ラボ | 仕分け・マッチング（6ステージ） | 4大物質、タンパク質の一次〜四次構造、DNAとRNA、消化酵素と基質、単量体と高分子、結合の名前 |
| 📝 研究員昇格試験 | クイズ（Lv1〜4・全64問） | 4大高分子の基本、構造、消化と代謝、総合（計算問題を含む）。毎回10問をランダムに出題し、8割以上で合格です |
| 🫁 消化管探検ミッション | 消化シミュレーション（3ミッション） | デンプン・タンパク質・脂肪が、口 → 胃 → 小腸 → 吸収 → 肝臓・細胞 と進むあいだに分解・吸収・利用されるようすを追います |
| 📖 分子図鑑 | 資料 | 構造式の簡略図とまとめ表（消化酵素の一覧を含む） |
| 📒 学習記録カード | 提出用 | 名前、各部屋の達成状況、バッジ、まちがいが多かった内容、確認コード |

- ステージをクリアするとXPがたまり、称号が上がります（見習い研究員 → 研究助手 → 研究員 → 主任研究員 → ラボリーダー → 博士）
- XPは各ステージの自己ベストから計算します。同じステージをくり返すだけではXPが増えないようにしています
- 進み具合と名前は、その端末のブラウザ（localStorage）にだけ保存されます。外部には送信しません

## 生徒への配布（GitHub Pages）

1. GitHub で **公開（Public）リポジトリ** を新しく作ります（例：`koubunshi-lab`）
   - 無料プランの GitHub Pages は公開リポジトリでしか使えません
   - このリポジトリには校務用のスクリプトも入っているので、配布用には別のリポジトリを作ることをおすすめします
2. `index.html` をそのリポジトリの直下にアップロードします
3. ［Settings］→［Pages］→ Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして保存します
4. 数分後に `https://<ユーザー名>.github.io/koubunshi-lab/` で公開されます。このURLかQRコードを Classroom で配ってください

※ HTML ファイルを Google ドライブに置いても、ドライブ上では動きません（ダウンロードして開けば動きます）。

## 授業での取り組み状況の確認

生徒は［📒 学習記録］を開いて、次のどちらかで提出します。

- カードのスクリーンショットを提出する
- ［記録をコピー］を押して、Classroom の課題や Google フォームの記述欄に貼り付ける

文字で提出された記録の末尾には **確認コード** が付きます。
学習記録画面の下にある「先生用：提出された記録の確認」に記録を貼り付けて［確認］を押すと、書きかえられていないかを照合できます。
これは簡易的なチェックです。プログラムを読める人なら回避できる仕組みなので、改ざんを完全には防げません。

## 問題の追加・修正

`index.html` をテキストエディタで開いてください。ファイルの先頭にある「問題データ」のブロックだけを編集します。

- **クイズ**（`QUIZ`）：`c` に並べた選択肢のうち、先頭が正解です（画面ではシャッフルされます）。`○`/`×` の2択にすると、○×問題として表示されます
- **仕分け**（`SORT_STAGES`）：`['カードの文字', 箱の番号]` を追加します。番号は 0 から数えます
- **組み立て**（`BUILD_STAGES`）と **消化**（`DIGEST_STAGES`）：パーツの記号はコメントに一覧があります
- `id` が重複しないようにしてください。学習記録の集計に使っています
- 編集したら、ブラウザで開き直して動作を確認してください

## 注意

- 同じ端末を複数の生徒で共有する場合、記録は上書きされます。ブラウザのプロファイルやアカウントを分けて使ってください
- ブラウザの閲覧データを消すと、記録も消えます
- 想定している端末は Chromebook（横長の画面・マウスまたはタッチパッド）です。タブレットやスマートフォンでも動きます
- 数字キー（1〜4）で選択肢を選べ、Enter キーで次へ進めます
