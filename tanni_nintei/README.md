# 単位認定会議資料 生成ツール

クラスごとの「学期末評定」帳票（.xlsx）から、学年全体の単位認定会議資料を1冊のExcelにまとめます。

```
python build_report.py 入力フォルダ 出力.xlsx [--club クラブ一覧.xlsx] [--master 科目マスタ.xlsx]
```

- 入力フォルダ: クラス別の帳票（1クラス1ファイル、形式は成績処理システムの「帳票レイアウト」）
- `--club`: 学年・組（クラス）・番号・氏名・クラブ（部活動）の見出しを持つ表。兼部は「、」区切りでも可
- `--master`: A列 科目名、B列 授業時数（省略時は出力ブックの「科目マスタ」シートに直接入力）

## 出力シート
概要 / 履修不認定一覧 / 欠時超過一覧 / 評定平均上位30名 / 皆勤者一覧（評定平均値付き）/ 登校不調者一覧 /
クラブ別評定平均 / 科目別評定分布 / クラス別比較 / クラブ所属 / 生徒一覧 / 履修明細 / 科目マスタ / 設定

## 判定基準（「設定」「科目マスタ」シートで変更可、数式で全シートに反映）
- 履修不認定: 欠時数の入力があり、評定・観点別が空欄（「評定なし」の科目を除く）
- 全科目で評定のない生徒: 履修不認定または籍なし（要確認）。順位・平均から除外
- 欠時超過: 欠時数 > 授業時数 × 1/3
- 皆勤: 欠席・遅刻・早退がすべて0
- 登校不調: 欠席10以上 または 遅刻10以上

入力データ・出力資料は個人情報を含むため `.gitignore` でリポジトリから除外しています。
